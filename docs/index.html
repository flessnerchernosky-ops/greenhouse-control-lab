温度有没有追过头？

虚线是目标温度，颜色对应四间温室。纵轴自动缩放，请看刻度。

把整局成绩一起看

方法整局平均偏离 °C最后 120 秒平均偏离 °C满功率等效秒

平均偏离是每步温差绝对值的平均数（MAE），不是 RMSE。加热用量是实际功率比例×时间之和，不是电费；同一场景跑完再比较。

P / I / D

纠正、记忆、看趋势

P 看现在冷多少；I 记住以前一直不够暖；D 看温度升得有多快。记忆能消除偏差，也可能越欠越多。

ANTI-WINDUP

别记做不到的欠账

加热器只有 50% 功率上限，想用 200% 也没用。记忆纠偏把“想发的”和“能发的”之间的差补回记忆，避免一直加码。

FEEDFORWARD

先补上散掉的热

知道现在室外有多冷，就先估计需要补多少热，再靠反馈纠正。估计错了，额外这一步也可能帮倒忙。

先猜，再用数据回答

  1. 选第二关，观察 120 秒目标从 34°C 降到 22°C 后，普通 PID 的加热器是否还在全力工作。
  2. 选第三关，比较记忆纠偏与前馈方法。哪一种更快察觉室外变冷？这是同一局内的对照。
  3. 第四关只把延迟从 20 秒调到 0，保持其他设置不变。记忆纠偏是否也能解决延迟？
  4. 第一关与第五关只改变散热估计。前馈是否一定比只有记忆纠偏更好？
