# 贡献 / Contributing

欢迎改进教学说明、双语翻译、可访问性、模型与实验分析。提交时说明问题、变动、复现条件、正反结果及局限；运行 `node test.cjs`、`node benchmark.cjs --check`、`python verify.py`。模型变更须解释并重建基准，保留原结果或清楚标记比较版本。不要把虚构温室结果描述为真实植物或硬件实验。

Contributions to teaching, translation, accessibility, models and analysis are welcome. Explain the problem, change, reproducible conditions, improvements/regressions and limits. Run `node test.cjs`, `node benchmark.cjs --check`, `python verify.py`. Explain model changes and regenerated baselines; preserve old findings or identify compared versions. Do not present fictional simulations as plant-growth or hardware experiments.
